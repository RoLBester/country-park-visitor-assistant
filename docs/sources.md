# What the snapshot covers

The retrieval date is 26 November 2026 in Hong Kong. Every source record has its own retrieval timestamp, publisher, URL and scope. The source register and passage file connect each answer to a page and a named section. Dates without a published value are JSON `null`. Source: Agriculture, Fisheries and Conservation Department (AFCD) for visitor guidance. [Source register](../data/snapshot.json) · [Indexed passages](../data/passages.json)

The current canonical Sai Kung centre page gives published hours. It gives no effective reopening date for its exhibition area. The snapshot does not reconstruct earlier operations from a removed notice or use a page’s last-update date as an opening date.

A whole-centre notice affects activities inside it. A programme notice applies only to its named activity. The status payload keeps the ordinary timetable, applicable notices and their sources separately visible. For an open-ended closure with a known start, the tool can report the notice between that start and the observation. Later dates are unconfirmed. For an undated observation, it does not supply a historical start. Three isolated [fixture cases](../evaluation/cases.json) exercise a one-day exhibition closure, the unaffected parent centre and an undated reopening. These invented notices never enter the visitor index.
